## Featured Projects

### File Encryption Application
A C++ application for encrypting and decrypting files using OpenSSL and AES-256. The project focuses on safe file handling, authenticated encryption design, key derivation, and reliable failure recovery.

### Personal Portfolio & Web Infrastructure
A containerized portfolio application built with ASP.NET Core and PostgreSQL. It includes database-backed content management and persistent application data. I also manage automated server instances utilizing Docker, Caddy, and n8n workflows.

### Cybersecurity Homelab
A controlled environment for studying network segmentation, traffic analysis, system hardening, and defensive security techniques using Linux and repurposed network hardware. Recent practical work includes extracting modem configurations via UART, wireless security auditing, and advanced iptables deployments.
